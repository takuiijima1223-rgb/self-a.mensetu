1. 面接の基本方針と評価配分（100点満点）

本面接は「欠員補充」ではなく、「自己実現をみんなのものに」のために自らを変容させ、自走できるかを判定するものです。

💡 【評価のポイント】1つのエピソードを深く掘り下げる

Phase 4（面接深掘り）やPhase 5（覚悟の確認）では、必ずしも全ての質問項目を実施する必要はありません。時間が限られている場合や、候補者の特性を引き出すために1つの項目を深く掘り下げる進行でも構いません。最終評価画面で「未実施」にチェックを入れることで、実施した項目の点数から自動的に30点満点に配点調整されます。

2. フェーズ別：運用手順と詳細基準

🤝 【Phase 1】お出迎え・着席（5点）

💡 メラビアンの法則：面接は入室の「数秒」で決まる

人の第一印象は「視覚情報（表情・態度）」と「聴覚情報（声のトーン）」で9割以上が決まります。これは候補者を評価するだけでなく、面接官自身が「自社の魅力を伝えるための第一印象」を作れているかという点でも非常に重要です。

  • 手順： 面接官は背筋を伸ばし、明るい表情と声で迎え入れます。候補者を案内中の「視覚・聴覚情報」を観察してください。
  • 評価基準： 笑顔の有無、アイコンタクトが取れるか、声のトーンは明るいか、清潔感や態度の余裕があるか。
  • 採点： 5点（非常に丁寧で好印象）〜0点（無愛想、目が合わない、清潔感がない）。

☕ 【Phase 2】アイスブレイク・基本確認（5点）

本音を引き出すための「心理的安全性の構築」と「対話力の確認」を行います。

メモと動画の断り：
「面接中、お話しいただいた内容を忘れないよう、こちらのPC（またはスマートフォン）でメモを取りながら進めさせていただきますね。また、途中A型事業所の概要説明の動画で説明する時間もありますので、リラックスして聞いてくださいね」

自己開示（面接官から）：
「〇〇でチーフをやっている〇〇です。前職は〜で未経験から入りました」と安心感を与える。

スタンス提示：
「ざっくばらんにいきますね」「気になることは都度聞いてください」と伝える。双方向での対話を促し、安心感を醸成します。

質問：
未経験の場合「障害福祉サービスってご存知ですか？」「知ったきっかけは？」知らない場合は「どんなイメージありますか？」
経験者の場合「障害福祉に携わるきっかけは何ですか？」

ニーズ把握（※必ず確認してください）：
「今日、一番気になっていることは何ですか？」と聞き、目的を絞ります。
ここで聞いた「気になっていること」を起点にして、面接を進めていきましょう。

💼 【Phase 3】経歴・条件確認・スタンス（5点）

💡 必須アクション：Phase 2の「ニーズ」に紐づけたヒアリング

ただ順番に質問をこなすのではなく、Phase 2で確認した「今日一番気になっていること（ニーズ）」を起点に話を展開してください。候補者の関心事に寄り添うことで、より深い本音を引き出すことができます。

● 経歴確認

「これまでのご経歴について、一番長く経験されたお仕事、あるいは一番ご自身が頑張ったと感じるお仕事について教えていただけますか？」

「そのお仕事では、具体的にどのような役割を担い、どんな業務をされていましたか？」

● スタンス（こだわり）の確認

「そのお仕事をされる中で、ご自身の中で『これだけは譲れない』『ここにはこだわっていた』というポイントはありますか？」

● 条件合致の確認

「今回、シフトや勤務時間、給与などの条件面については募集要項の通りとなりますが、現状で相違やご懸念はございませんか？」

🔍 【Phase 4】面接質問・深掘り（30点：各10点）

具体的なリスクペルソナ（不動 固・依存 待子・古井 説子）を炙り出します。

Q1：提案経験（IQ/EQ）

質問： 「提案経験は？ もし若手から『自動化しましょう』と反対意見が出たらどう対話しますか？」

Q2：達成感と失敗（IQ/自責思考）

質問： 「最も失敗したことは？ 支援した方が再発して戻ってきたら、自分をどう評価しますか？」

Q3：喜怒哀楽の割合（自己客観視）

質問： 「喜怒哀楽は何割ですか？ 負の感情をどう解消しますか？」

🔥 【Phase 5】覚悟の確認：RJP（30点：各10点）

現場の「厳しさ」を伝え、覚悟（合意）を確認します。オープンクエスチョンで本人の思考を引き出します。

  • 現場作業への従事： 最初の数週間は一緒に作業に入ってもらい、その後は一人で現場を任されることもあります。「このような裁量の大きさや、一人で対応する場面について、ご自身はどのように受け止めていますか？」
  • 厳しい現実への耐性と動画視聴： 現場のリアルな状況を知ってもらうため、ここで**「利用者の障害特性動画」**を視聴してもらいます。その後、「もし動画のような予期せぬ状況に直面した場合、〇〇さんならまずどのように対応しようと考えますか？」と質問します。
  • 自発性の要求： 当社では提案しやすい環境がある反面、自ら考え、わからないことは自分から発信して聞きに行くスタンスが強く求められます。「これまで、自分から主体的に動いて周りを巻き込んだり、自発的に行動したエピソードがあれば教えてください。」

✨ 【Phase 6】ビジョン・やりがいの共有（得点なし）

RJPで「厳しい現実」を伝えた後は、事業所の「良いところ・やりがい」や「将来ビジョン」を伝え、魅力付け（動機付け）を行います。※ここは評価（採点）は行わず、惹きつけに専念してください。

1. 事業所の魅力・やりがいの提示：
事業所の「良いところ」や「仕事の楽しさ・やりがい」を伝えます。同時に、大変な部分も「どう解決・成長につながるか」という前向きな文脈で伝えます。

💡 伝えるポイント例：
・利用者の成長（できることが増えた等）を間近で見られる喜び。
・スタッフ同士が相談しやすく、助け合えるチーム環境。
・「大変なこと」の変換例：「利用者さんへの対応で悩むこともありますが、それをチームで共有し、解決策を見つけた時に支援員としての大きな成長を感じられます。」

2. 入社後の仕事内容とキャリアイメージの共有：
入社後、具体的にどのような状況でどんな仕事に取り組んでもらうか、そして半年後、1年後の「期待する姿（将来ビジョン）」を伝え、候補者の目標とすり合わせを行います。

💡 伝えるポイント例：
・「最初は〇〇の作業支援から入ってもらい、徐々に面談などもお任せしていく予定です。」
・「半年後には〇〇を任せたいと思っていますが、イメージは湧きますか？」
・「ゆくゆくはリーダーとして、事業所全体を引っ張る存在になっていただきたいと期待しています。」

3. 現状の共有と「共に創る（一緒に頑張ろう）」スタンス：
現在の事業所のリアルな状況（課題も含めて）と、その解決に向けた取り組みを伝えます。「まだ完璧ではないからこそ、〇〇さんと一緒に良くしていきたい」と伝え、仲間としての意識を醸成します。

💡 伝えるポイント例：
・「現在、〇〇という課題がありますが、チームで〇〇という工夫をして改善を進めています。」
・「完成された組織ではなく、これから作っていくフェーズです。ぜひ〇〇さんの力を貸していただき、一緒に良い事業所を創っていきましょう！」

⚖️ 【Final】対人援助適性・現場カルチャーフィット（20点）

面接全体を通しての「対人援助職としての適性」を【加点方式】（0〜5点）で評価します。

  • ① 受容性・傾聴姿勢
  • ② 自己開示と誠実さ
  • ③ 感情の安定性とストレス対処
  • ④ 理念への共感・チーム貢献意欲

Final Phase: 現場適性 (各5点・加点方式)

① 受容性・傾聴姿勢

0

5点:相手の話に深く頷き、全く否定せずに受け止める姿勢が自然にできている。

4点:相手の話を肯定的に聞き、適度な相槌や共感の言葉を返せている。

3点:一般的なコミュニケーションとして、適切に話を最後まで聞くことができている。

2点:話は聞いているが、反応が薄く、受け止めているかやや分かりにくい。

1点:少し自分の意見を被せがちで、相手の話を最後まで聞けないことがある。

0点:相手の言葉を遮る、または「でも」「いや」など否定から入る傾向が強い。

② 自己開示と誠実さ

0

5点:自身の弱みや失敗を全く飾らずに話し、等身大の自分をオープンに見せられている。

4点:失敗談などを自分から率直に語り、誠実な姿勢が伝わってくる。

3点:少し取り繕う部分はあるが、嘘偽りなく誠実に答えようとしている。

2点:本音が見えにくく、表面的な回答や建前での受け答えが多い。

1点:都合の悪い質問をはぐらかす、または他責にする傾向が見られる。

0点:「何でもできます」と過剰にアピールする、明らかな嘘や矛盾がある。

③ 感情の安定性とストレス対処

0

5点:想定外の質問に対しても全く焦らず、常にフラットな感情を保って対話できる。

4点:少し驚いてもすぐに状況を把握し、冷静かつ前向きに対応できる。

3点:少し戸惑うことはあっても、自ら落ち着きを取り戻して対応できる。

2点:やや動揺が表に出やすく、返答に焦りや焦燥感が感じられる。

1点:ストレスを感じると言葉にトゲが出たり、表情が露骨に曇る。

0点:予期せぬ質問で明らかに不機嫌になる、またはパニックになりやすい。

④ 理念への共感・チーム貢献意欲

0

5点:理念に深いレベルで共感し、自らチームに貢献したいという強い意欲がある。

4点:理念をよく理解し、他者と協調して働くことの大切さを認識している。

3点:理念には一定の理解を示しており、現場スタッフとも協力して働く姿勢が見える。
